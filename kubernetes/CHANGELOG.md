# Changelog

All notable changes to this plugin are documented in this file.
Format: [Keep a Changelog](https://keepachangelog.com/). Versioning: [SemVer](https://semver.org/).

## [0.1.3] - 2026-11-26

### Fixed
- The icon shows again. It now points at Iconify's `/prefix/name.svg` URL; the old `prefix:name` form answers 404, so Fleet fell back to a generic icon.

## [0.1.1] - 2026-06-20

### Added

## [0.1.0] - 2026-06-17

### Added
